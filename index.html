cad-drawing-reader

  • In development
  • Built for SelectAM
  • Private repository

Reads 2D mechanical drawings, from vector PDFs or scans, and turns them into structured part data: the views on the sheet, every dimension and tolerance, surface finish and material, and the part's overall size and approximate volume.

Everything runs on the machine it's installed on. There's no cloud service, API key or network call anywhere in the pipeline, so a drawing never leaves the computer reading it. It has a web app for reviewing results, a command line for whole folders and a REST API.

Every rule in the pipeline is a drafting convention with a citation (ISO 128, 129, 286, 1302 and 5457) rather than a setting tuned to particular drawings. Thresholds are measured across the whole drawing set, and each measurement is written next to its threshold in the code.

Stack
Python, FastAPI, OpenCV, PyMuPDF, Tesseract, PaddleOCR, PostgreSQL, Redis, Next.js, Docker
Outputs
Excel, CSV and JSON, overlay images, a 3D-ready model file and true-size DXF views for CAD
Where it stands
Vector PDFs read reliably. Scanned drawings are the hard part and where most of the current work goes.

BorealLM

  • In development
  • Research project
  • Private repository

An experiment with small language models: how much can the right pretraining data teach a small transformer when its size and compute budget are fixed? The first specialization, BorealLM-AM, is for additive manufacturing, starting with laser powder bed fusion (LPBF).

It's designed to train on one laptop with 16 GB of memory. Right now I'm building the corpus: open-access LPBF papers, deduplicated, then scored for relevance, role, theme and quality before any of them reach training.

Research questionHow does domain-specific pretraining data composition affect the technical knowledge and language-modeling performance of small transformer models under a fixed parameter and compute budget?
First model
BorealLM-AM-10M, about 10 million parameters
Dataset
BorealAM-Micro, built from open-access papers indexed by OpenAlex
Evaluation
An additive-manufacturing benchmark, held-out domain perplexity, tokenizer efficiency and training efficiency
Stack
Python, OpenAlex API, JSONL data pipelines

  1. Now

    Corpus

    Collect, deduplicate and label open-access LPBF papers.

  2. Next

    Pretraining

    Train BorealLM-AM-10M on the corpus, on one laptop.

  3. Then

    Evaluation

    Benchmark, held-out perplexity, tokenizer and training efficiency.
