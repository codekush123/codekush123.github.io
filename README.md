# codekush123.github.io

Source for my personal site, <https://codekush123.github.io>. Plain HTML, CSS and JavaScript with no build step: GitHub Pages serves the `main` branch as it is.

- `index.html`: all of the page content
- `assets/site.css`, `assets/site.js`: styles and behaviour
- `assets/fonts/`: Inter and JetBrains Mono, under the SIL Open Font License
- `og.png`, `favicon.svg`, `favicon-32.png`, `apple-touch-icon.png`: link preview and icons
